# TownyDuels

Arena-based 1v1 and team dueling plugin built for Paper Minecraft servers with Towny integration.

## Features
- **Arena Management**: Dynamic creation, configuration, and bounds detection for duel arenas.
- **Custom Kits**: In-game kit creator with inventory saving, effects, and weapon presets.
- **State Isolation**: Player inventory, health, and buffs are saved and restored after duels.
- **Anti-Exploit System**: Disables command execution, teleportation, and item drops during matches.
- **Leaderboards & Stats**: Tracks wins, losses, ELO rating, and match history.

## Requirements
- Java: 17+
- Server: Paper / Purpur 1.20+
